## EN Description (English)

**Thermo-Steam Calc & Tools** is an advanced thermodynamic calculator for **steam** and **air** (dry and moist), powered by the certified **CoolProp** library (using the **IAPWS** formulation for water/steam and ASHRAE psychrometrics).

**Key Features and Modules:**
* Thermodynamic properties calculator for steam and air.
* Design calculations (e.g., filled pipe mass, pipe diameter selection).
* Advanced engineering unit converter.
* Reference tables with physical and chemical constants.
